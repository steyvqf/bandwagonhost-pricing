## 买之前值得知道的几条限制

- **没有 DDoS 防护**。这是优化线路的代价之一，一旦遭遇大流量攻击，IP 会被空路由处理。如果是容易被攻击的业务，要有心理准备。
- **官方不做备份**。存储本身是 RAID-10 冗余，硬盘坏了数据不会丢，但服务条款明确说明搬瓦工不负责备份数据，重要数据要自己定期备份（KiwiVM 面板里有快照功能可用）。
- **流量用完会停机**，不会额外扣费，等到下一个计费周期自动恢复，或者升级套餐、购买加量。
- **切换机房会消耗流量**。KiwiVM 面板里换机房是免费的，但迁移过程的数据传输会计入当月流量，机房如果满员会提示不可选。
- **客服是英文工单制**。没有在线聊天，提交工单后经常先收到一个叫 Martin C 的机器人回复，人工回复通常要等一段时间，节假日更慢。对响应速度有期待的，要提前调整预期。
